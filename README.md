# ✂️ FadeHouse — Sistema de Gestão para Barbearias

Sistema web completo para barbearias, com área do cliente para agendamentos e painel administrativo para controlar o dia a dia do negócio. Tudo em uma única aplicação, sem necessidade de instalação.

🔗 **[Testar o sistema online](https://mathzogliari.github.io/fadehouse-barbearia/)**

---

## ✨ Funcionalidades

### Área do cliente
- Criação de conta e login
- Novo agendamento com confirmação
- Consulta dos próprios agendamentos

### Painel administrativo
- **Dashboard** com os agendamentos do dia
- **Agendamentos** em lista e em calendário
- **Clientes** cadastrados
- **Barbeiros** (equipe)
- **Estoque** de produtos
- **Relatórios financeiros** com gráficos e faturamento por período
- **Caixa do dia** e histórico de caixas
- **Configurações**
- Busca e registro de auditoria das ações

## ▶️ Como rodar localmente

1. Baixe o arquivo `index.html` deste repositório
2. Abra-o em qualquer navegador (basta dar dois cliques)

---

## ⚠️ Limitações

- Os dados ficam salvos apenas no navegador de quem usa, sem banco de dados nem servidor
- A autenticação é simulada no próprio front-end, então o projeto é uma demonstração e não deve ser usado em produção com dados reais
